# Taskly — Executive Summary

Taskly is a modern to-do application built with React and TypeScript. It helps users organize daily tasks, plan around due dates, manage custom lists, and stay focused using a clean and polished productivity workflow.

The project combines practical UX design with a scalable front-end architecture. It includes smart task views, drag-and-drop task ordering, local persistence, wallpaper personalization, and productivity summaries.

Key technologies include React, TypeScript, Vite, Tailwind CSS, and a component-driven architecture with centralized state management.

This repository demonstrates a complete front-end product experience focused on personal productivity, with features designed to be simple, fast, and user-friendly.

## Highlights

- task creation and tracking
- smart lists for Inbox, Today, Upcoming, and Starred views
- custom list management
- due-date-based grouping and filters
- drag-and-drop organization
- local browser persistence
- user personalization through wallpapers and themes
- email drafting workflow for task-related communication

## Why it matters

Taskly is a strong example of a polished front-end app built around real user needs: clarity, speed, and organization. It shows thoughtful product decisions and a maintainable engineering structure suitable for a modern portfolio or product prototype.
